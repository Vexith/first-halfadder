# Simple Half-Adder

This is my first VeriLog project and the introduction to VeriLog for me, so i decided to create a simple circuit known as the Half-Adder.
Also, it contains a test program to test the Half-Adder

## how it works?

The circuit is built using only two logic gates, the XOR gate (when both input bits are different, returns 1, if they are the same returns 0) serving as the sum result and the AND gate (when all input bits are 1, returns 1, when any input bits are 0, returns 0) serving as the carry. So we give the 2 inputs (both numbers we want to sum it up), do the sum and carry (XOR and AND), put the carry output first and put the sum last. that's how it works!
